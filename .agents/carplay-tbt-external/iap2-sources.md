# iAP2 / CarPlay route guidance — annotated bibliography
Collected 2026-11-05. Raw copies of the key files are in `clones/raw/` (no full repo clones). Pinned commits so line refs stay valid.
Confidence: H = decompiled Apple binary and/or on-car capture; M = receiver-firmware RE or single-source; L = forum/anecdote.

## Primary: iAP2 wire format, RE'd from Apple binaries (best sources)
1. luka-dev/mib2q-carplay-rgi @ df73e061 — `docs/cluster-and-rgi/IAP2_ROUTE_GUIDANCE_TLVS.md`, `hook/routeguidance/rgd_tlv.h`, `rgd_tlv.c` (MHI2Q Audi/VW head unit hook, 2026). Ground truth = accessoryd 23G71 (iOS 26.6) `+[ACCNavigation* keyForType:]` decompile, MHI3 libesoiap2 / dio_manager type-info strings, on-car logs. Covers: all TLV IDs of 0x5200-0x5204, ManeuverType 0..53 (+255 NotSet), distance units, driving side, junction types, lane sub-TLVs, angle sentinels, 0x5200 injection pitfalls, ident group 0x001E layout. H.
   - Also `docs/cluster-and-rgi/LANE_GUIDANCE.md`, `MANEUVER_MAPPING.md` (what iOS actually sends for angles; U-turn sign rules), `THIRD_PARTY_NAV_APPS.md` + archive copy `docs/archive/internal-reference-2026-10-29/cluster-and-rgi/THIRD_PARTY_NAV_APPS.md` (which apps populate which CPManeuver fields; CarPlay.framework serializer). H (static analysis of IPAs, not tested on car except AMap owner note).
2. kamgurgul/mib2q-carplay @ 5c460600 — `docs/rgd/rgd-tlv.md` (same TLV map, compact), `docs/re/ios/maps-maneuvers.md` (Apple Maps accNav enum + signed ExitAngle, decompile anchors iOS 26.6), `dongle/hw301/FINDINGS.md` (dongle drops 0x5201/2/4 unless patched). H. (Appears to be a sibling/fork lineage of luka-dev.)
3. f-io/LIVI @ e4ae798e — `native/crates/iap2-csm/src/messages/route_guidance.rs`, `identification.rs`: clean typed schema (param id -> name -> wire type) for 0x5200-0x5204 and RouteGuidanceDisplayComponent. M-H (matches Luka's tables exactly; adds 0x5200 param 4 and 0x5201 param 21 as i16).
4. catplay-labs/catplay `core/catplay_csm/src/msg/iap2.rs`, fifthBro/mh2p-cluster, yuedizhibo/MHI2Q-CarPlay-AltScreen, Lanye-z/MHI2Q-CarPlay-MMI-Mirror — forks/relatives of #1 (same rgd_tlv.h). Not independently verified.
5. harman-f/mhi2_altscreen_carplay `modules/navigation/source/src/common/mibr_rgi_wire.h` — independent small implementation: ident group 30 (=0x1E), component id 1237 example, builds 0x5200 (component id + empty flag params for SourceName/SourceSupportsRouteGuidance/SupportsExitInfo) and 0x5203. States "layout as accepted by iOS" per Luka. M.
6. shilapi/xcertplay & shihabal3amri/DiPlay (`iap2/catalog/Iap2Endpoint.kt`, `Iap2IdentificationClient.kt`) — Kotlin iAP2 message catalog listing 0x5200..0x5204 with direction (0x5200/0x5203 accessory->iPhone; 0x5201/2/4 iPhone->accessory). Thin. M.
7. 0312birdzhang/harbour-sailplay `NAVIGATION.md` (Oct 2026) — the *sender* side: Sailplay (Sailfish OS phone emulating an iPhone) to HSAE receiver. RE of receiver `libiAP2.so`: 0x5200 param0 = BE16 component id, params 1-3 empty flags; 0x5201/0x5202 field storage; DrivingSide is 0x5202 param **8**; component declared via ipodconfig.xml `RouteGuidanceDisplayComponent` ID 9, 30-char text limits. Quirk: this HSAE build encodes stop (0x5203) component id little-endian. M.
8. lvalen91/CPC200-CCPA_resources @ a5831314 `documentation/02_Protocol_Reference/usb_protocol.md` (also abuharsky/carplay copy) — CPC200/Carlinkit dongle firmware RE (Feb-Mar 2026). Dongle converts iAP2 route guidance to `NaviJSON` (MediaData 0x2A subtype 200): keys NaviStatus, NaviRoadName, NaviOrderType, NaviManeuverType (=CPManeuverType 0-53), NaviTurnAngle (an enum NOT degrees), NaviTurnSide (0=RHD,1=LHD), NaviRoundaboutExit (1-19), NaviRemainDistance. **Dongle strips** JunctionType, JunctionElementAngle/ExitAngle, AfterManeuverRoadName and lane guidance. Live capture: 12 roundabouts all with junction 0/angle 0 on that dongle path; iPhone sent 21 params per 0x5201; 0x5202 burst of ~20 messages (~200 ms) at route start; 0x5201 ~1 Hz. H for dongle behaviour.
## Apple public docs
9. https://developer.apple.com/documentation/carplay/cpmaneuvertype (iOS 17.4+) — public case names; matches iAP2 ordering by name (raw values not published on page; confirm via CPManeuver.h — see Xamarin wiki diff https://github.com/xamarin/xamarin-macios/wiki/CarPlay-iOS-xcode13.0-beta2 for the older 0..~26 values). H for names.
10. https://developer.apple.com/documentation/carplay/cpmaneuver, `cprouteinformation` — CPManeuver properties (maneuverType, junctionType, trafficSide, junctionElementAngles, junctionExitAngle, linkedLaneGuidance, highwayExitLabel). Cluster support iOS 16.4, HUD metadata iOS 17.4 (secondary summary).
11. https://www.oligo.security/blog/pwn-my-ride-exploring-the-carplay-attack-surface — iAP2 over Bluetooth framing for wireless CarPlay (checksums/control messages). Not nav-specific. M.
